---
name: Rently visual direction
description: User-stated visual direction for Rently
---

Rently should have a more technical look, fewer texts, and a distinctive brand.

**Why:** The user requested changing the colors and appearance to be more technical and less text-heavy, and creating a distinctive brand.

**How to apply:** Use this direction when updating Rently's homepage and branding; do not infer approval of a specific palette or logo proposal.

Rently must offer a choice between Arabic and English, not an Arabic-only interface.

**Why:** The user requested: «اضف خيار لتغير اللغة العربية و الانجليزية».

**How to apply:** Keep both languages available when adding or changing user-facing screens.

After sign-in, focus the interface on the owner's actual data and reduce excess explanatory or promotional text.

**Why:** The user requested: «اجعل الواجهة بعد تسجيل الدخول مركزة على البيانات وقلل الكلام الكثير الزائد».

**How to apply:** Treat the signed-in owner workspace separately from the public marketing page; keep essential validation and payment confirmations.

Important primary actions should be bright blue, and all buttons should have rounded corners.

**Why:** The user requested clear blue for important buttons and rounded edges for every button.

**How to apply:** Use blue for primary actions across public and signed-in Rently screens, while keeping every button and button-style link rounded.
